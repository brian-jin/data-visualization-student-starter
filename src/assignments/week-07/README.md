# Week 7 NYC "Same-ification" Map
 
Inspired by two sources from Observable, I implemented Hexbin and Zoom to Bounding Box into my map.
 
## Sources
 
- **Hexbin map**, Mike Bostock, Observable (D3): https://observablehq.com/@d3/hexbin-map
  Reference for aggregating point data into hexagonal bins and rendering them on a geographic map.
- **Zoom to bounding box**, Mike Bostock, Observable (D3): https://observablehq.com/@d3/zoom-to-bounding-box
  Reference for zooming and panning the map to the bounding box of a selected feature.
- **Color palette**, Coolors: https://coolors.co/palette/c9e4ca-87bba2-55828b-3b6064-364958
  Five-color palette (`#C9E4CA`, `#87BBA2`, `#55828B`, `#3B6064`, `#364958`) used for the hexbin color ramp and the recolored base map.
